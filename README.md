# PANOPTICON

*Population-aware exploration of bacterial pangenomes.*

PANOPTICON is a modular toolkit for exploring population structure, accessory-genome variation, ecological signal, and gene-family sharing before formal GWAS or machine-learning analyses.

A bacterial pangenome is not merely a feature matrix. Apparent host, source, geographic, or phenotypic associations can be generated by clonal population structure, uneven sampling, study effects, and lineage-specific gene content. PANOPTICON is designed to make those patterns visible and test whether they persist under balanced and lineage-aware comparisons.

## Current capabilities

- Panaroo and PIRATE input through a shared loader
- pangenome composition and gene-frequency summaries
- per-genome gene-family counts
- PCA, MDS, and optional UMAP
- pangenome and core-genome accumulation curves
- stratification by any categorical metadata column
- rarefied group comparisons
- observed and rarefied gene-family sharing
- Jaccard, Dice, overlap, and directional containment metrics
- group-core and group-specific repertoire comparisons
- UpSet, heatmap, network, dendrogram, and summary figures
- optional exact nucleotide or protein allele sharing
- lineage-collapsed sensitivity analyses

## Installation

```bash
git clone https://github.com/Benizao1980/PANOPTICON.git
cd PANOPTICON

mamba env create -f environment.yml
conda activate panopticon
```

The scripts can be run directly from `scripts/`.

```bash
python scripts/pangenome_io.py --help
python scripts/pangenome_plotting.py --help
python scripts/pangenome_stratification.py --help
python scripts/pangenome_ecology.py --help
```

## Panaroo input

Preferred files:

```text
gene_presence_absence.Rtab      preferred binary matrix
gene_presence_absence.csv       annotations and locus tags
summary_statistics.txt          optional summary
```

For phylogenetics:

```text
core_gene_alignment.aln
core_gene_alignment_filtered.aln
```

For exact allele sharing, retain or generate family-specific FASTA/alignment files. PANOPTICON can run matrix-based analyses from an Rtab alone; if the CSV is absent or empty, gene names and annotations are omitted rather than causing the analysis to fail.

## Quick start

Inspect a Panaroo pangenome:

```bash
python scripts/pangenome_io.py \
  --pangenome-tool panaroo \
  --pangenome-out panaroo_output
```

Generate initial figures:

```bash
python scripts/pangenome_plotting.py \
  --pangenome-tool panaroo \
  --pangenome-out panaroo_output \
  --outdir panopticon_qc \
  --pangenome-bars \
  --gene-freq \
  --gene-counts \
  --pca
```

Stratify by a metadata field:

```bash
python scripts/pangenome_stratification.py \
  --pangenome-tool panaroo \
  --pangenome-out panaroo_output \
  --meta metadata.tsv \
  --meta-id-col id \
  --group-col ecology_group \
  --outdir ecology_stratified \
  --rarefaction-per-group
```

Quantify group sharing:

```bash
python scripts/pangenome_ecology.py \
  --pangenome-tool panaroo \
  --pangenome-out panaroo_output \
  --meta metadata.tsv \
  --meta-id-col id \
  --group-col ecology_group \
  --outdir ecology_sharing \
  --min-group-n 20 \
  --min-group-family-count 2 \
  --min-group-family-prevalence 0.01 \
  --rarefy \
  --rarefy-n 40 \
  --rarefaction-reps 100 \
  --group-core-threshold 0.99 \
  --all-plots
```

## Interpretation

Raw shared-family counts are strongly affected by sample size. Prefer rarefied similarity for comparisons among groups. Gene-family sharing does not by itself demonstrate recent horizontal transfer. Interpret results alongside a core-genome phylogeny, lineage assignments, study provenance, and geography.
