# Licence choice required

PANOPTICON currently has no declared software licence. A public repository without a licence is source-visible but does not grant reuse rights.

Recommended choices:

- **MIT**: permissive and simple; suitable if broad academic and commercial reuse is desired.
- **BSD-3-Clause**: similarly permissive with a non-endorsement clause.
- **GPL-3.0**: requires redistributed derivative software to remain open under the GPL.

Choose one licence before the first stable release and replace this file with the standard licence text.
